# refused above the link's. With Agents, the PC linking starts an agent conversation on the other
# for a project both have: it runs with that PC's own login and settings, in its own clone, and
# pushes its commits to a new branch. Full access isn't offered. Checks have no server, so links are
# made up, and an agent task runs here against a made-up server, with a check login that commits.
